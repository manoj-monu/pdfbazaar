PDF Compression Kya Hai?

PDF compression ek technique hai jisme software images ka DPI (resolution) reduce karta hai aur hidden metadata hata deta hai. File ka size 80% tak chota ho sakta hai — text quality waisi hi rehti hai.

  • Less Compression: Best quality, printing ke liye ideal
  • Recommended: Balanced — email/portal uploading ke liye
  • Extreme: Maximum size reduction, sharing ke liye
